# Coding Agent Instructions

- Inspect the repository before editing.
- Work only on the assigned GitHub issue.
- Make the smallest correct change.
- Add or update tests.
- Run formatting, linting, type checking, and tests.
- Never commit secrets, API keys, tokens, private keys, or `.env` files.
- Never force-push.
- Never modify production credentials.
- Never merge or deploy.
- Open a pull request and explain the root cause, changes, tests, and risks.
